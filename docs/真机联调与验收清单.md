本清单用于首次接入和每次重大版本/标定/地图变更后的回归。执行运动项必须有受训人员现场监护并可直接触达物理急停。

## 2. 物理与环境安全

- [ ] 物理急停位置、作用范围和复位方法已现场确认。
- [ ] 机械臂和底盘工作区清空，线缆固定并留有运动余量。
- [ ] 地面平整、干燥，无坡道、楼梯、悬空、玻璃和未隔离危险区。
- [ ] 地图中的禁行线覆盖所有低矮、透明、悬空和镂空障碍风险。
- [ ] 底盘电量、充电状态、软硬急停和错误码正常。
- [ ] 机械臂、夹爪、相机和控制箱无松动、破损、异响或异常温升。
- [ ] 已确定人工接管口令和立即停止流程。

## 3. 只读连通性

- [ ] 电脑只接入机器人控制网，未把控制端口暴露到互联网。
- [ ] LM3 Web 页面可访问，实际地址与记录一致。
- [ ] `examples/read_lm3_status.py` 能读取系统信息、状态和急停原因。
- [ ] UP 9001 页面可读取版本、地图、楼层、电量、急停和定位。
- [ ] WATER TCP 端口可建立连接，但尚未发送运动命令。
- [ ] RK 插件页可查看 camera、camera_calibrater、apriltag 状态。
- [ ] 所有时间戳来源和时区已记录，日志能关联同一事件。

## 4. LM3 独立测试

- [ ] 先在仿真或离线环境检查目标关节/TCP 是否在允许范围。
- [ ] 真机以最低可行速度、无负载、单条动作开始。
- [ ] `start_sys`、动作 ID、等待完成、暂停、停止和急停路径分别验证。
- [ ] 关节限位、速度、加速度、TCP 工作空间和奇异位形保护已在模型外实现。
- [ ] 夹爪开合、力度和稳定状态单独验证；夹取失败不会继续危险回撤。
- [ ] 断开客户端不会意外下电、停止其他合法任务或遗留运动。

## 5. UP 独立测试

- [ ] 当前地图、楼层、定位和激光与现场一致。
- [ ] 选择一个短距离、无遮挡、非充电点的测试点位。
- [ ] 保存 `/api/move` 的 `uuid`、`task_id` 和完整状态序列。
- [ ] 到达必须同时满足状态成功和现场运动停止。
- [ ] `/api/move/cancel` 后等待回到 `idle`，再允许下一任务。
- [ ] 障碍停止、目标占用、不可达、断网和急停均进入失败关闭。
- [ ] 自动回充、充电触片接触和回充后定位校正通过。
- [ ] 若测试 `joy_control`，存在本地看门狗并在丢失输入时持续零速停止。

## 6. 视觉与抓取

- [ ] 记录相机索引、分辨率、棋盘格尺寸、tag family/size/ID。
- [ ] 内参和手眼标定各使用 15-30 个分布合理姿态，并保存误差证据。
- [ ] signal/Modbus 通信方式在插件和 LBD 中一致。
- [ ] 使用实际标签尺寸，打印时为 100%，无页面缩放。
- [ ] 当前安装重新生成 offset/cell2tag，没有复用交付示例值。
- [ ] 标签丢失、识别超时、位姿跳变和错误 ID 会安全退出。
- [ ] 抓取先空载、低速、小范围验证，再使用真实物体。
- [ ] 接近、夹取、回撤、失败退避和急停路径都有明确完成判据。

## 7. 整机协调

- [ ] 底盘到点并稳定后才授权机械臂运动。
- [ ] 机械臂回到运输/安全姿态后才授权底盘运动。
- [ ] 每个子系统只有一个运动写入者。
- [ ] 导航、遥控、机械臂、人工示教和 VLA 的优先级已定义。
- [ ] 任一状态超时或通信断开都会撤销后续动作授权。
- [ ] 同时按整机急停和底盘急停，实际作用范围与文档/现场标识一致。

## 8. VLA 专项

- [ ] LeRobot 适配器已经修复并通过 AST、单元测试和离线回放。
- [ ] 数据集是 LM3-UP 本机单臂数据，不是直接复用双臂 RoboTwin 映射。
- [ ] 相机、关节、夹爪和动作时间戳同步误差满足项目要求。
- [ ] 推理先通过离线和影子模式，尚未直接控制机器人。
- [ ] 模型外安全层覆盖动作限幅、工作空间、碰撞、看门狗和急停。
- [ ] 首次真机 VLA 固定底盘、无负载、最低速度、小工作空间、逐步执行。
- [ ] 模型异常、超时、NaN/Inf、越界动作和重复动作均有可验证的拒绝路径。

## 9. 验收证据

每项通过都应保存：

- 软件/固件版本、配置摘要和 Git 提交。
- 原始请求、响应、callback/notification 和状态时间线。
- 现场视频或传感回放，包含正常路径和至少一个负向路径。
- 地图、标定、测试点位和安全参数备份。
- 执行人、监护人、日期、结论和未解决风险。

“页面能打开”“API 返回 OK”“单次动作成功”都不能单独作为整机验收结论。
