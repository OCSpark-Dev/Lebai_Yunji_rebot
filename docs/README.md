# LM3-UP 文档中心

本目录把原始交付文件、公开 SDK 代码事实和后续研发建议分开记录。所有默认地址、页面截图和示例参数都需要在真机上重新发现和确认。

## 推荐阅读顺序

1. [LM3-UP 开发指南](LM3-UP开发指南.md)：先理解整机边界、网络和控制分层。
2. [SDK 与子模块指南](SDK与子模块.md)：确定机械臂、底盘、ROS、视觉和 LeRobot 分别使用什么。
3. [真机联调与验收清单](真机联调与验收清单.md)：连接设备前建立现场记录和安全门槛。
4. [LingBot-VLA 接入评估](LingBot-VLA接入评估.md)：仅在基础控制和数据采集稳定后进入 VLA 阶段。
5. [CLAUDE.md](../CLAUDE.md)：需要查完整手册细节、冲突项和 API 陷阱时阅读。

## 事实优先级

1. 人身、电气和机械安全采用多份资料的严格交集。
2. 整机操作优先采用 2025 简明手册；UP 内部细节参考云迹硬件/软件手册。
3. WATER 字段以交付 API 手册和现场软件版本为准。
4. 乐白 API 以固定的官方 SDK 代码和当前控制器版本为准。
5. 视觉流程以 RK 指南为主，场景行为以 LBD 中的 `lua_source` 为准。
6. 截图 IP、标签 ID、标定值、地图和偏移量都是示例，不是现场真值。
